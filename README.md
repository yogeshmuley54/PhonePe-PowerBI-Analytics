# 📊 PhonePe Power BI Analytics Dashboard

An interactive **Power BI dashboard for Digital Payments Analytics**, designed to analyze transaction performance, user growth, payment success rates, customer segments, and service-level trends.

This project demonstrates the use of **Power BI, DAX, data modeling, time intelligence, interactive visualizations, slicers, and report tooltips** to transform digital payment data into actionable business insights.

---

## 📌 Project Overview

Digital payment platforms generate large volumes of transactional and customer data. Analyzing this data effectively can help businesses understand transaction trends, customer behavior, service performance, and payment success.

This Power BI project provides an analytical view of:

- 👥 User growth and customer acquisition
- 💳 Transaction volume and transaction value
- 📈 Month-over-month transaction performance
- ✅ Payment success rate
- 🛍️ Service-level transaction performance
- 👤 Customer/user segmentation
- 📅 Monthly transaction trends
- 📊 Weekend vs. non-weekend transaction behavior

---

## 🎯 Business Objectives

The dashboard was developed to answer key business questions such as:

1. How are the number and value of transactions changing over time?
2. How is the user base growing year over year?
3. What is the overall payment success rate?
4. Which services contribute the most to transaction value?
5. How does transaction behavior vary across user segments?
6. How do transactions differ between weekends and non-weekdays?
7. How is monthly transaction performance changing?
8. Which areas require further investigation from a business perspective?

## 📊 Dashboard Overview

### Key Performance Indicators

The dashboard includes the following KPIs:

- **Total Users**
- **Total Transactions**
- **Total Transaction Value**
- **Payment Success Rate**
- **Transaction MoM %**
- **Transaction Value MoM %**

These KPIs provide a quick overview of the overall health and performance of the digital payment ecosystem.

---

## 📈 Key Dashboard Analysis

### 1. Transaction Performance

Analyzes monthly transaction volume and transaction value to understand overall payment activity and identify changes in transaction behavior over time.

### 2. User Growth

Tracks user growth by joining year to understand customer acquisition and expansion of the user base.

### 3. Payment Success Analysis

Monitors payment success rate across different periods to evaluate transaction reliability and identify potential changes in payment performance.

### 4. Service-Level Analysis

Breaks down transaction value by payment/service category to understand which services contribute to overall transaction activity.

### 5. Customer Segmentation

Analyzes transaction behavior across different age/user segments to understand customer contribution and behavioral patterns.

### 6. Weekend vs. Non-Weekend Analysis

Compares transaction activity between weekends and non-weekdays to identify differences in payment behavior.

## 🧩 Data Model

The Power BI model includes key tables such as:

- `All_Transactions`
- `All_Users`
- `Date Table`
- `Measures`

A dedicated **Date Table** is used to support time-based analysis and month-over-month calculations.

The model follows a structured analytical approach to separate transactional data, user information, date attributes, and measures.
